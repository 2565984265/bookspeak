# 📚 BookSpeak

> 通过阅读一本书学英语——阅读、词汇、口语三位一体

## 这是什么

BookSpeak 是一个**开源的英语学习工具**，核心理念：

**拿一本你真正想读的书（比如《纳瓦尔宝典》英文版），一页一页读下去，读完这本书，英语也提升了。**

不是背单词表，不是刷题，而是**用阅读驱动学习**。

## 核心功能

| 功能 | 说明 |
|------|------|
| 📖 **分段阅读** | 把书拆成小段，每天读一点 |
| 📝 **点击查词** | 点任意单词，弹出释义+发音 |
| 🎯 **生词本** | 只背这本书里的生词，书中重复出现时高亮提醒 |
| 🎤 **朗读评估** | 读完后 AI 评分+发音纠错 |
| 💬 **AI 口语对话** | 基于书中内容提问，用英语回答 |
| 📊 **进度追踪** | 可视化：读了多少、学了多少词、口语进步了多少 |

## 与现有工具的区别

| 工具 | 功能 | 缺少 |
|------|------|------|
| LWT | 阅读+标记生词 | 没有口语 |
| Anki | 背单词 | 没有阅读上下文 |
| Duolingo | 游戏化学习 | 不是真实内容 |
| **BookSpeak** | **阅读+词汇+口语，以一本书为核心** | ✅ 完整闭环 |

## 技术栈

- **前端**：React 18 + Vite + React Router
- **状态**：Zustand
- **语音**：Web Speech API（浏览器原生，免费）
- **AI**：OpenAI API（查词、口语对话）
- **存储**：localStorage + IndexedDB（纯前端，零配置）

> **无需后端。** 所有功能在浏览器完成。

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/2565984265/bookspeak.git
cd bookspeak

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 打开浏览器访问 http://localhost:3000
```

## 使用流程

1. **导入一本书** —— 上传 TXT/EPUB/PDF
2. **每天读一段** —— 点击生词查释义，标记认识/不认识
3. **读完练口语** —— 朗读段落，AI 评分
4. **AI 对话** —— 基于书中内容提问，用英语回答
5. **追踪进度** —— 看读完几章、学了多少词、口语进步了多少
